## 1. 测试范围

- **测试目标**：确认鸿蒙版在核心使用场景上与 Telegram 官方 iOS 客户端的行为一致。
- **用例来源**：57 个日常高频场景；其余从 iOS 官方源码列出的 538 个用户可见操作入口中选取。共 287 个用例。
- **暂不纳入的功能**：付费功能（Premium、Stars、礼物）、创作者功能（Stories 发布、直播、变现），以及调试类和默认隐藏的选项。这些功能或涉及支付、账号安全等敏感环节，不属于日常聊天的核心功能，因此不在本期的开发和测试计划内。

## 3. 测试方法

- 每个用例的通过标准只写用户能看到的结果，执行前确定，执行中不再修改。
- 鸿蒙真机和 iOS 模拟器执行同一用例，由脚本驱动，全程录屏，并保留截图和应用日志。
- 执行者和独立评审各自根据截图与录屏判定结果，两者不一致的用例再看证据裁定。
- 结果分两种：**通过**，通过标准的每一条都在截图或录屏中可见；**待开发**，功能尚未完成，或尚未达到通过标准。
